# 臭臭监督官

一款 Windows 桌面休息提醒工具。连续使用电脑达到设定时间后，臭臭会覆盖所有显示器，提醒你休息眼睛。

## 功能

- 默认专注 45 分钟、休息 5 分钟，可设置为 1～180 分钟和 1～30 分钟。
- 休息前 1 分钟发送系统通知，不提供延后按钮。
- 休息画面覆盖全部显示器并轻微变暗，使用透明背景的臭臭美术形象和轻微呼吸动效，不播放声音。
- 提醒关闭方式可选择“立即关闭”或“30 秒后关闭”，默认保护前 30 秒。
- 锁屏或休眠时暂停；达到 5 分钟后重置专注周期。
- 托盘支持暂停 30 分钟、1 小时、到明天及立即恢复。
- 开机自启动可设置，默认关闭。
- 简体中文和英文界面，默认跟随系统。
- 每天最多检查一次 GitHub Release，只提示下载，不自动安装。

## 本地运行

需要 Node.js 20 或更高版本。

```powershell
pnpm install
pnpm start
```

## 测试与打包

```powershell
pnpm test
pnpm dist
```

安装包输出到 `dist/`。Windows 首次安装可能显示“未知发布者”，这是未购买代码签名证书的正常现象。

推送 `v*` 标签后，GitHub Actions 会自动测试、构建并创建 GitHub Release：

```powershell
git tag v0.1.0
git push origin v0.1.0
```

## 隐私

程序不读取键盘、鼠标活动，不使用摄像头，不判断人员是否离开，也不会上传使用记录。原始猫咪照片和视频位于 Git 忽略目录，不会被提交。
